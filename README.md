# Security Camera 🎥

Домашняя охранная камера своими руками. Следит за кадром, **узнаёт ваших в лицо**,
пишет **видео со звуком** и присылает в **Telegram**: сначала фото, потом клип.

Работает на **macOS, Linux и Windows**. Запускается одной командой, в фоне — без
всплывающих окон консоли.

---

## Возможности

- **Экономит CPU.** Тяжёлые нейросети (распознавание лиц, трекинг человека)
  запускаются только когда в кадре есть движение. В простое — почти ничего не ест.
- **Узнаёт своих.** Распознавание лиц через InsightFace: положили фото — знает человека.
- **Пишет со звуком.** Клип = 5 секунд до события + 5 секунд после, с дорожкой микрофона.
- **Уведомления в Telegram.** Сначала быстрый снимок, затем видео со звуком.
- **Автозапуск.** На Windows — фоновой задачей `HomeCameraService` (Планировщик),
  с автоперезапуском при падении.

## Что нужно

- **Python 3.10+** (лучше 3.11)
- **ffmpeg** — для видео со звуком
- **Камера** и **микрофон**

Установка ffmpeg:
```bash
# macOS
brew install ffmpeg
# Ubuntu/Debian
sudo apt install ffmpeg
# Windows: скачайте с https://ffmpeg.org и добавьте в PATH
```

## Готовый релиз (Windows, без установки Python)

Скачайте `HomeCamera_v1.0_Windows.zip` (раздел **Releases**), распакуйте в любую папку и:

1. впишите `telegram.token` и `telegram.chat_id` в `config.yaml`
   (или просто запустите `START_CAMERA.bat` — он откроет файл в блокноте);
2. положите фото людей в папку `known/` и один раз выполните `HomeCamera.exe enroll`;
3. запустите **`START_CAMERA.bat`** — камера работает в фоне, без окна консоли.

Автозапуск при входе в систему — `INSTALL_AUTOSTART.bat`, удалить — `UNINSTALL.bat`.
Модели при первом запуске докачиваются сами (или заранее — `download_models.bat`).
Сборка релиза описана в `docs/BUILD.md`.

## Как получить токен бота (2 минуты)

1. В Telegram откройте **[@BotFather](https://t.me/BotFather)** → команда `/newbot`
   → придумайте имя → получите **токен** вида `123456789:AA...`.
2. Откройте **своего** бота (ссылка от BotFather) и нажмите **Start**.
3. Узнайте свой **chat_id**: напишите боту **[@userinfobot](https://t.me/userinfobot)** —
   он пришлёт ваш Id.
4. Впишите оба значения в `config.yaml`:
   ```yaml
   telegram:
     token: "123456789:AA-ваш-токен"
     chat_ids: [ваш_id]
   ```

## Папка с фотографиями — `known/`

**Положите в папку `known/` по одному фото на каждого человека.**
Имя файла = имя человека, так оно и будет показываться в уведомлениях:

```
known/
├── pavel.jpg
├── anna.png
└── guest.JPG
```

Затем один раз выполните:
```bash
./venv/bin/python enroll.py      # Windows: venv\Scripts\python.exe enroll.py
```
Это создаст `known/embedding.npy` — «память» о лицах. Добавили новые фото —
запустите `enroll.py` ещё раз (эмбеддинги усредняются).

## Настройки — `config.yaml`

Все параметры собраны в одном файле, с комментариями — см. `config.example.yaml`.
Ключевое:

| Параметр | Что делает |
|----------|-----------|
| `telegram.token`, `telegram.chat_ids` | куда слать уведомления |
| `recording.pre_seconds` / `post_seconds` | сколько секунд писать до/после события |
| `recording.mux_audio` | вшивать ли звук микрофона прямо в mp4 |
| `face.threshold` | строгость распознавания (0.5 по умолчанию) |
| `motion.*` | чувствительность детектора движения |
| `audio.*` | микрофон, частота, буфер |

> `config.yaml` добавлен в `.gitignore` — ваши токены не попадут в репозиторий.

## Автозапуск в фоне (Windows)

Папка `service/` — тихий запуск и автозапуск через Планировщик задач под именем
**HomeCameraService**:

# от имени администратора
powershell -ExecutionPolicy Bypass -File service\install.ps1

Подробнее — `service/README.md`. Там же `build_service.ps1` для сборки
`HomeCameraService.exe` (чтобы процесс в Диспетчере назывался по-человечески).

## Как это работает (коротко)

1. **Motion gate** — детектор движения (MOG2) на маленьком кадре. Нет движения —
   тяжёлые модели не запускаются (экономия CPU).
2. **Лицо** — при движении распознаём лица и сравниваем с `known/`.
   Совпадение на нескольких кадрах подряд = событие.
3. **Запись** — пишем mp4: 5 секунд до события (кольцевой буфер) + хвост после.
   Звук с микрофона вшивается в файл.
4. **Telegram** — сразу фото, затем видео со звуком (перекодируется в H.264/AAC).
