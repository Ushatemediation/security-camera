# Security Camera 🎥

Охранная камера на домашнем компьютере: следит за кадром, **узнаёт людей в лицо**,
пишет **видео со звуком** и присылает его в **Telegram** (сначала фото, затем клип).

Есть **готовый архив для Windows — ставить ничего не нужно** (Python не требуется).

## 🆕 Release 2.1 (Windows)

Скачать: **[Releases](../../releases)** → `HomeCamera_v2.1_Windows.zip` → распаковать →
вписать токен в `config.yaml` → запустить **`START_CAMERA.vbs`** (работает без окна консоли).

- **Индикатор камеры гаснет** — на Windows через драйвер камеры (DirectShow → `IKsControl`), драйвер не меняется; сторож `LEDGuard` держит его выключенным в любом приложении. Наш софт и системные процессы Windows — в исключениях.
- **Проверка параллельной работы**: `HomeCamera.exe camwatch --parallel` — кто держит камеру и откроется ли поток вторым клиентом (с fps).
- **Консоль не появляется**: `START_CAMERA.vbs` (wscript, скрытое окно), подпроцессы ffmpeg — с `CREATE_NO_WINDOW`.
- **Стейт-машина**: запись → склейка → отправка идут внутри программы (`Pipeline`), без внешних вызовов.
- **Синхрон A/V**: CFR-таймлайн с дублями кадров — «дёргание» и «плывущий» звук исправлены, тонкая подстройка `audio.sync_offset_ms`.
- **Мониторинг камеры**: `HomeCamera.exe camwatch --once` — кто ещё держит камеру (реестр ConsentStore).
- **ffmpeg вшит** — ничего скачивать не нужно.

## 🟢 Заказчику: как запустить (3 шага)

1. Скачайте **`HomeCamera_Windows.zip`** из раздела **[Releases](../../releases)** и распакуйте в любую папку.
2. Откройте `config.yaml` и впишите **токен бота** и **chat_id** (как получить — ниже).
   Положите фотографии людей в папку `known/` (имя файла = имя человека, например `pavel.jpg`).
3. Дважды щёлкните **`START_CAMERA.bat`** — программа работает в фоне, окно консоли не появляется.

При появлении человека придёт **фото**, затем **видео со звуком**. Записи — в `recordings/`.

> Внутри архива есть файл **`ПРОЧТИ_МЕНЯ.txt`** — те же шаги, подробнее.
> Автозапуск при включении ПК — `INSTALL_AUTOSTART.bat`. Остановить/удалить — `UNINSTALL.bat`.

### Как получить токен бота (2 минуты)
1. В Telegram: **[@BotFather](https://t.me/BotFather)** → `/newbot` → придумайте имя →
   получите **токен** вида `123456789:AA...` → впишите в `config.yaml` (`token`).
2. Откройте **своего** бота и нажмите **Start**.
3. Узнайте свой **chat_id**: напишите **[@userinfobot](https://t.me/userinfobot)** →
   впишите полученное число в `config.yaml` (`chat_ids`).

```yaml
telegram:
  token: "123456789:AA-ваш-токен"
  chat_ids: [123456789]
```

## Что умеет

- **Экономит CPU** — тяжёлые нейросети включаются только при движении в кадре.
- **Узнаёт своих** — распознавание лиц (InsightFace): положили фото → знает человека.
- **Пишет со звуком** — клип = 5 секунд до события + 5 после, с дорожкой микрофона.
- **Уведомления в Telegram** — снимок «цель в кадре» + видео со звуком (обе отправки — в фазе SENDING).
- **Стейт-машина** — запись → склейка (ffmpeg) → отправка идут по явным состояниям: IDLE, RECORDING, PROCESSING, SENDING_TELEGRAM.
- **LED камеры Logitech** — подсветка (C922/C920) включается при старте и гаснет при выходе.
- **Автозапуск** (Windows) — фоновая задача `HomeCameraService`.
- **Мониторинг камеры** (Windows) — видно, если камеру заняло другое приложение: `python camera_watcher.py --once`.

## Настройки (`config.yaml`)

Все параметры — в одном файле, с комментариями (см. `config.example.yaml`):

| Параметр | Что делает |
|----------|-----------|
| `telegram.token`, `telegram.chat_ids` | куда слать уведомления |
| `recording.pre_seconds` / `post_seconds` | сколько секунд писать до/после события |
| `recording.mux_audio` | вшивать ли звук микрофона прямо в mp4 |
| `recording.fps` | целевой FPS видео: `0` — авто по камере, `30` — жёстко |
| `audio.sync_offset_ms` | подстройка синхрона звука: `+` = звук позже, `-` = раньше |
| `face.threshold` | строгость распознавания (0.5 по умолчанию) |
| `motion.*` | чувствительность детектора движения |
| `audio.*` | микрофон, частота, буфер |
| `system.prevent_sleep` | не давать ПК уходить в сон, пока работает камера |
| `led.enabled` / `led.mode` | подсветка камеры Logitech: выкл / вкл / авто |

> `config.yaml` в `.gitignore` — ваши токены не попадут в репозиторий.

### Если видео «дёргается» или звук «плывёт»

Кадры доходят до писателя неравномерно (детекция грузит цикл), поэтому видео
пишется CFR по слотам: пропуски закрываются дублем последнего кадра, и
длительность клипа всегда равна реальному времени — дорожки не разъезжаются.
В логе после каждой записи есть строка:

```
Запись завершена: 2026-10-31_14-02-11.mp4: 900 кадров, 30.0с @ 30.0fps (подача ≈18.2fps, дубли 354, дропы 0)
```

- **`подача` сильно ниже `fps`** — цикл не успевает кормить писателя: уменьшите
  `motion.process_fps` / `person_tracking.person_fps` или поставьте `recording.fps`
  по реальной подаче.
- **«губы» стабильно чуть раньше/позже** — постоянный сдвиг устройства ввода:
  `audio.sync_offset_ms: 100` (плюс = звук позже, минус = раньше).
- **Квадратики/«битые» блоки на движении** — это ограничение кодека `mp4v`
  (запись через OpenCV), а не синхрона. Лечится записью сразу в H.264 через
  ffmpeg-пайп — отдельная доработка.

## 📺 Веб-архив на сервере (опция)

Записи можно складывать не только в Telegram, но и на **свой сервер** — с галереей,
где удобно листать видео за день. Серверная часть лежит в `server_app/`
(Flask + gunicorn + systemd, отдаёт HTTPS и чистит старое по лимиту диска).

```yaml
server:
  enabled: true
  url: "https://IP-сервера:8080"
  token: "выдаётся сервером"
  verify_tls: false
  camera: "home"
```

Приложение выгружает каждый готовый клип (уже со звуком) на сервер в фоне.

## 🛠 Для разработчика

### Запуск из исходников (macOS / Linux / Windows)
```bash
git clone https://github.com/Ushatemediation/security-camera.git
cd security-camera

./setup.sh        # macOS/Linux: venv + зависимости + модели + config.yaml
setup.bat         # Windows

# впишите config.yaml, положите фото в known/ (лица распознаются автоматически)
./start.sh        # macOS/Linux,  (Windows: start.bat)
./start.sh --preview
```

### Полезные команды
```bash
make run        # запуск          make test      # автотесты
make preview    # с окном превью  make selftest  # проверка Telegram
make cpu        # CPU в простое   make enroll    # распознать лица из known/
```
Тест без камеры: `./run_local.sh --source путь/к/видео.mp4`

### Сборка standalone-релиза (PyInstaller)
- macOS: `./build_mac.sh` → `dist/HomeCamera/`
- Windows: `build.bat` → `PACK_RELEASE.bat` → `HomeCamera_v2.1_Windows.zip`
- Без своего Windows: **GitHub Actions → `build-windows` → Run workflow** (или пуш тега `v*`) —
  робот соберёт `HomeCamera_v2.1_Windows.zip` и выложит в артефакт/Release.

Подробности — `docs/BUILD.md`.

### Структура
```
security_camera/
├── main.py             # главный цикл: движение → лицо → запись (стейт-машина)
├── notifier.py         # Telegram: фото + видео со звуком (фазы обработки/отправки)
├── led_control.py      # LED-подсветка Logitech C922 (UVC)
├── camwatch.py camera_watcher.py  # кто ещё использует камеру (Windows)
├── audio.py paths.py launcher.py
├── enroll.py selftest.py
├── service/            # фон и автозапуск (Windows)
├── known/              # фото лиц (+ embedding.npy)
├── recordings/         # готовые mp4
├── docs/  tests/
└── HomeCamera.spec     # сборка PyInstaller
```
