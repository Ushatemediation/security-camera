# Changelog

## 2.0.0 — Windows Release

### Новое

- **Стейт-машина пайплайна** — класс `Pipeline` в `main.py`: `IDLE → RECORDING →
  PROCESSING (склейка ffmpeg) → SENDING_TELEGRAM → IDLE`. Склейка и отправка —
  внутренние методы программы, внешних вызовов нет.
- **LED-подсветка камеры Logitech** (`led_control.py`) — UVC XU через pyusb,
  режимы `led.mode: 0/1/2` (выкл/вкл/авто), включается при старте. На Windows без
  WinUSB-драйвера фича мягко пропускается и на запись не влияет.
- **Мониторинг доступа к камере** (`camera_watcher.py`) — журнал Windows
  `CapabilityAccessManager\ConsentStore\webcam`; в собранном приложении:
  `HomeCamera.exe camwatch --once`.
- **Синхрон A/V** — видео пишется CFR по слотам с дублями кадров, метки аудио —
  по началу блока, `audio.sync_offset_ms` для тонкой подстройки,
  `aresample=async=1` против дрейфа. Клип больше не «сжимается» по времени.
- **Диагностика** — при старте логируются параметры камеры (разрешение, fps,
  fourcc), после каждой записи: кадры, длительность, подача, дубли, дропы.
- **`--version`** у `HomeCamera.exe` / `launcher.py`.
- **`led` в exe**: `HomeCamera.exe led --probe|--set N` — проверить/переключить
  подсветку без исходников (macOS/Linux; на Windows подсветкой управляет драйвер).
- **ffmpeg вшит в приложение** — пакет `imageio-ffmpeg` везёт бинарь внутри себя,
  поэтому `ffmpeg.exe` больше не нужно скачивать и класть рядом с exe: видео со
  звуком работает «из коробки» на чистой машине.

### Исправлено

- «Дёргание» картинки и сдвинутый/«плывущий» звук в записях.
- Потеря последнего клипа при завершении программы: shutdown дожидается
  финализации записи и разрешает отправку до остановки нотификатора.
- Зависание финализированных записей в очереди, если они пришли во время чужой
  отправки.
- Двойная финализация одной записи при выходе.
- Обрыв ретраев отправки по `stop_event` при закрытии программы.
- Артефакты у краёв кадра при нечётных размерах видео (mp4v).

## 1.0.0 — первый Windows-релиз

- Охранная камера: motion gate → распознавание лиц → запись со звуком.
- Отправка в Telegram (фото + видео), веб-архив на своём сервере.
- Автозапуск Windows (`HomeCameraService`), сборка PyInstaller.
